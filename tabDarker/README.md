# Tab Darker Chrome Extension

A lightweight Chrome Extension that lets you instantly black out any active tab and restore it using simple keyboard shortcuts.

---

## ⌨️ Shortcuts

- **Black out active tab:** `Space` + `,`
- **Restore tab to normal:** `Space` + `.`

---

## 🚀 How to Install & Load in Chrome

1. Open Google Chrome (or any Chromium browser like Brave, Edge, Opera, Vivaldi).
2. Navigate to `chrome://extensions` in the URL bar.
3. Enable **Developer mode** using the toggle switch in the top-right corner.
4. Click on the **Load unpacked** button in the top-left corner.
5. Select the folder:
   ```text
   /home/adirchy/Projects/extensions/tabDarker
   ```
6. The extension is now installed!

---

## 💡 How to Use

1. Open any webpage or tab (e.g. YouTube, Wikipedia, GitHub, etc.).
2. Press **`Space` + `,`** at the same time (or hold `Space` and tap `,`): the entire tab turns pure black.
3. Press **`Space` + `.`** at the same time (or hold `Space` and tap `.`): the tab returns to normal.

> **Note:** For tabs that were already open before installing/reloading the extension, refresh the page once for the extension to inject. Chrome restricts extensions on internal pages like `chrome://` or Chrome Web Store pages.
